# InitORM / .github

Default community health files for the [InitORM](https://github.com/InitORM) organization.

GitHub applies the contents of this repository as defaults to every InitORM repository that does not provide its own version of a given file. See [Creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for the propagation rules.

## What lives here

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Organization profile page shown at <https://github.com/InitORM> |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant — applies to all packages |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Contribution workflow shared across packages |
| [`SECURITY.md`](SECURITY.md) | Vulnerability reporting policy |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask questions and get help |
| [`GOVERNANCE.md`](GOVERNANCE.md) | Project governance and decision making |
| [`FUNDING.yml`](FUNDING.yml) | Sponsorship targets shown in the **Sponsor** button |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/) | Default issue forms (English + Turkish) |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Default pull-request template (bilingual) |
| [`DISCUSSION_TEMPLATE/`](DISCUSSION_TEMPLATE/) | Discussion category forms |
| [`workflow-templates/`](workflow-templates/) | Reusable GitHub Actions templates surfaced in the **Add workflow** gallery |

Most files are written in English. Turkish translations live next to the original with a `.tr.md` suffix — for example [`CONTRIBUTING.tr.md`](CONTRIBUTING.tr.md).

> **Note on Discussion templates and workflow templates.** Unlike the community health files above, `DISCUSSION_TEMPLATE/` only applies to discussions created in the source repository (typically the org-level Discussions sourced from this repo). `workflow-templates/` is surfaced in the **Add workflow** gallery of every InitORM repository.
