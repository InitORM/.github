# Getting support

Türkçe sürüm: [SUPPORT.tr.md](SUPPORT.tr.md)

InitORM is maintained by a single person in their spare time. Using the right channel for the right question helps everyone get answers faster.

## Where to ask

| You want to… | Use |
| --- | --- |
| Report a confirmed bug | The **Issues** tab of the affected package repository |
| Ask "how do I…?" or share an idea | [GitHub Discussions](https://github.com/orgs/InitORM/discussions) |
| Report a security vulnerability | See [SECURITY.md](SECURITY.md) — **do not** use public channels |
| Read about an API | The GitHub Wiki of the relevant package |

## Before you open an issue

1. Search existing [issues](https://github.com/InitORM) and [discussions](https://github.com/orgs/InitORM/discussions) — your question may already be answered.
2. Make sure you are on the latest minor version of the affected package (`composer update initorm/<package>`).
3. Prepare a minimal reproduction. Issues without a reproducer are difficult to act on and may be closed.
