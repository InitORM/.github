# Code of Conduct

Türkçe sürüm: [CODE_OF_CONDUCT.tr.md](CODE_OF_CONDUCT.tr.md)

## Our pledge

The InitORM project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct. By participating in any InitORM repository, discussion, or community space, you agree to abide by its terms.

The full text of the Contributor Covenant 2.1 is available at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

A summary of what the Covenant covers:

- A welcoming, respectful, and inclusive environment for everyone.
- Standards for positive behavior and examples of unacceptable behavior.
- Enforcement responsibilities of project maintainers.
- A scope that includes all official project spaces.
- Guidelines for reporting concerns and the consequences for violations.

## Reporting concerns

If you experience or witness behavior that violates this Code of Conduct, please report it to the maintainer in confidence:

- **Email**: <info@muhammetsafak.com.tr>
- **Subject line**: `[InitORM Conduct] <short summary>`

All reports are reviewed promptly and confidentially. The reporter's identity is protected.

## Enforcement

The maintainer is responsible for clarifying and enforcing this Code of Conduct. Consequences for violations follow the **Enforcement Guidelines** in the Contributor Covenant 2.1, ranging from a private warning to a permanent ban from project spaces, depending on severity.
