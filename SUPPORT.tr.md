# Destek alma

English version: [SUPPORT.md](SUPPORT.md)

InitORM, tek bir kişi tarafından boş zamanlarında geliştirilmektedir. Doğru kanalı doğru soru için kullanmak herkesin daha hızlı yanıt almasını sağlar.

## Nereye sormalı

| Yapmak istediğiniz | Kullanın |
| --- | --- |
| Doğrulanmış bir hata bildirimi | İlgili paket reposunun **Issues** sekmesi |
| "Nasıl yapılır?" sorusu veya öneri | [GitHub Discussions](https://github.com/orgs/InitORM/discussions) |
| Güvenlik açığı bildirimi | [SECURITY.tr.md](SECURITY.tr.md) — **public kanal kullanmayın** |
| API dokümantasyonu | İlgili paketin GitHub Wiki'si |

## Issue açmadan önce

1. Mevcut [issues](https://github.com/InitORM) ve [discussions](https://github.com/orgs/InitORM/discussions) içinde arama yapın — sorunuz zaten yanıtlanmış olabilir.
2. Etkilenen paketin en güncel minor sürümünde olduğunuzdan emin olun (`composer update initorm/<paket>`).
3. Minimal bir reprodüksiyon hazırlayın. Reprodüksiyon içermeyen issue'lar üzerinde işlem yapmak zordur ve kapatılabilir.
